# Imported one-dimensional modules

These Lean modules supply results used by the higher-dimensional
universal-completeness proof:

- [Theorem12/](Theorem12/) contains completeness, uniqueness, duality, and
  Fourier lemmas.
- [Theorem14/](Theorem14/) contains further analytic and density lemmas.
- [SpectralGapsPrelim/BirkhoffPointwise/](SpectralGapsPrelim/BirkhoffPointwise/)
  contains pointwise ergodic machinery for torus rotations.

The higher-dimensional proof is in [UniversalCompletenessHD/](../UniversalCompletenessHD/),
with supporting modules in [IntegerFrequenciesHD/](../IntegerFrequenciesHD/).
For the public statement, begin at [showcase.lean](../../showcase.lean).
