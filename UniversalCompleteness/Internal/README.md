# Universal-completeness proof modules

[UniversalCompletenessHD/](UniversalCompletenessHD/) contains the proof
applied by the [showcase](../showcase.lean). Start with
[Basic.lean](UniversalCompletenessHD/Basic.lean) for the exported library
theorem and [PublicAssembly.lean](UniversalCompletenessHD/PublicAssembly.lean)
for the assembly of separation, density, `L¹` uniqueness, and `Lᵖ`
completeness.

[IntegerFrequenciesHD/](IntegerFrequenciesHD/) supplies the torus, Fourier,
and density lemmas imported by this proof. The analytic modules under
[OneDimensional/](OneDimensional/) support the Section 6, item (1) theorem;
they are not additional showcased conclusions.
