# Imported one-dimensional modules

[Theorem12/](Theorem12/), [Theorem14/](Theorem14/), and
[SpectralGapsPrelim/BirkhoffPointwise/](SpectralGapsPrelim/BirkhoffPointwise/)
contain analytic results imported by the higher-dimensional
integer-frequency proof. The Birkhoff modules supply pointwise ergodic
machinery for torus rotations.

The package's `lakefile.lean` uses this directory as the source root for
these libraries. For the public statement, begin at
[showcase.lean](../../showcase.lean).
