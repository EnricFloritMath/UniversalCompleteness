# Integer-frequency proof modules

[IntegerFrequenciesHD/](IntegerFrequenciesHD/) contains the proof applied by
the [showcase](../showcase.lean). Start with
[Basic.lean](IntegerFrequenciesHD/Basic.lean) for the exported library
theorem and [PublicAssembly.lean](IntegerFrequenciesHD/PublicAssembly.lean)
for the assembly of density, `L¹` uniqueness, and `Lᵖ` completeness.

[OneDimensional/](OneDimensional/) contains analytic lemmas imported by the
proof. Its [README](OneDimensional/README.md) identifies those modules.
